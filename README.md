# 📌 Pin Matcher

A sleek and interactive **Pin Matcher** web application built with a modern UI. This project demonstrates core JavaScript logic, DOM manipulation, and responsive design principles.

## 🚀 Features

- **Secure Pin Generation:** Generates a random 4-digit security pin instantly.
- **Interactive Keypad:** A fully functional calculator-style keypad for user input.
- **Validation System:**
  - ✅ **Success Notification:** Displays when the input matches the generated pin.
  - ❌ **Error Notification:** Displays when the input is incorrect.
- **Security Constraints:** Includes a "Try Left" attempt tracker to limit incorrect guesses.
- **Smart Controls:** Features 'C' for clear and '<' for backspace to enhance user experience.

## 🛠️ Technologies Used

- **HTML5:** Structured for semantic clarity.
- **CSS3:** Styled with a modern aesthetic, focusing on clean layouts and responsive design.
- **JavaScript (ES6):** Powering the pin generation, input handling, and matching logic.
